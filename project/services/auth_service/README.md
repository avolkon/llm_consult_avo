# auth_service

Сервис аутентификации (FastAPI) для системы LLM-консультаций.

В связи с ограничением работы Telegram на территории РФ,
транспорт чата в проекте сменён с Telegram на мессенджер MAX (dev.max.ru): bot_service трактуется как клиент MAX (события, JWT, Celery, LLM);
детали API и стек подлежат уточнению.
