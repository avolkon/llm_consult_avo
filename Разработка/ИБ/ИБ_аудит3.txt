================================================================================
  ИБ_аудит3 — автоматический аудит зависимостей (uv audit)
  LLM Consultation System — auth_service, bot_service
================================================================================

Дата фиксации отчёта: 2026-05-10
Инструмент: uv 0.11.13, команда `uv audit` (экспериментальный режим; предупреждение
            инструмента: рекомендуется `--preview-features audit` в будущих версиях).

Контекст: единичный прогон из корня сервисов после `uv sync` (lock-файлы актуальны
на момент запуска). Код выхода 1 у `uv audit` при наличии уязвимостей или adverse
status — ожидаемо.

--------------------------------------------------------------------------------
  auth_service (project/services/auth_service)
--------------------------------------------------------------------------------

Просканировано пакетов: 39 (в отчёте инструмента: «39 packages»).
Найдено известных уязвимостей: 3.

1) pytest 8.4.2
   - GHSA-6w46-j5rx-g56g — уязвимая обработка tmpdir
   - CVE-2025-71176
   - Исправление: pytest >= 9.0.3
   - Область: группа dev (тесты), не прод-рантайм приложения.
   - Ссылка: https://nvd.nist.gov/vuln/detail/CVE-2025-71176

2) starlette 0.46.2
   - GHSA-2c2j-9gv5-cj73 — возможный DoS при разборе больших multipart
   - CVE-2025-54121
   - Исправление: starlette >= 0.47.2
   - GHSA-7f5h-v6xp-fcq8 — DoS O(n^2) через заголовки Range в FileResponse
   - CVE-2025-62727
   - Исправление: starlette >= 0.49.1

Итог по auth_service: обновить транзитивно/прямо fastapi/starlette до версии с патчем
(минимум 0.49.1 по второму CVE); pytest — при обновлении dev-группы до >= 9.0.3.

--------------------------------------------------------------------------------
  bot_service (project/services/bot_service)
--------------------------------------------------------------------------------

Просканировано пакетов: 63.
Найдено известных уязвимостей: 2.
Adverse status: 1.

1) ecdsa 0.19.2
   - GHSA-wj6h-64fc-37mp — Minerva timing attack на P-256 в python-ecdsa
   - CVE-2024-23342
   - В отчёте uv: «No fix versions available» (исправленной версии в индексе не указано)
   - Происхождение в дереве bot_service: транзитивно от прямой зависимости
     `python-jose` (`bot_service/pyproject.toml`); для снижения поверхности можно
     в перспективе заменить на PyJWT по аналогии с auth_service.

2) pytest 8.4.2
   - Те же GHSA-6w46-j5rx-g56g / CVE-2025-71176, исправление >= 9.0.3
   - Dev-зависимость.

3) rsa — статус «archived» (архивный проект)
   - Риск: отсутствие сопровождения upstream; транзитивно от `python-jose` в bot_service.

Итог по bot_service: приоритет — понять, кто тянет ecdsa/rsa; для pytest — обновление
dev; по rsa — замена или исключение из дерева при возможности.

--------------------------------------------------------------------------------
  Сводные рекомендации
--------------------------------------------------------------------------------

- Повторять `uv audit` (или `make audit` из корня репозитория) при изменении
  `pyproject.toml` / `uv.lock` и в CI.
- После обновления версий — прогон `uv run pytest` в обоих сервисах и регрессия API.
