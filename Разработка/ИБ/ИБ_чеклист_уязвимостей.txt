--- Секреты и конфигурация ---
[ ] JWT_SECRET в auth и bot совпадают, ≥32 символов, не плейсхолдеры из примеров
[ ] MAX_BOT_TOKEN и OPENROUTER_API_KEY не в git; ротация при утечке проработана
[ ] Пароли Redis/AMQP в production не default (guest и т.п.)
[ ] .env и auth.db с локальными данными не попадают в артефакты CI/образы публично

--- Сеть и инфраструктура ---
[ ] Redis и RabbitMQ недоступны из интернета; доступ только из VPC/внутренней сети
[ ] На хосте не торчат 6379/5672/15672 наружу без необходимости
[ ] TLS для Redis/AMQP включён там, где требует политика
[ ] Reverse proxy: лимит размера тела, таймауты, при необходимости WAF

--- Auth Service ---
[ ] Rate limit на POST /auth/login адекватен (IP / доверенный прокси)
[ ] Rate limit на POST /auth/register включён или обосновано отсутствие
[ ] Политика паролей соответствует требованиям (длина, сложность)
[ ] Ошибки логина/регистрации не дают лишней информации злоумышленнику (по политике)
[ ] /docs и OpenAPI отключены или защищены в production
[ ] Security headers применяются (как минимум на auth); HSTS при HTTPS

--- Bot Service и webhook ---
[ ] Подлинность входящих webhook MAX подтверждена по документации (подпись/секрет/IP)
[ ] Security headers на FastAPI webhook при необходимости выровнены с auth
[ ] JWT в чате: пользователи осведомлены о риске копирования токена в мессенджер

--- Redis / Celery / Outbox ---
[ ] Нет анонимной записи в Redis извне; ACL/пароль
[ ] Очередь Celery защищена; нельзя опубликовать задачу без авторизации брокера
[ ] max:outbox: риск подделки сообщений оценён; длина text ограничена при необходимости

--- LLM и данные ---
[ ] Промпты в логах: минимизация ПДн; срок хранения и доступ к логам
[ ] Политика prompt injection / контент-модерации задокументирована для заказчика
[ ] OPENROUTER_BASE_URL указывает только на доверенный хост

--- Зависимости и артефакты ---
[ ] uv audit (или аналог) прогнан; критичные CVE закрыты или принято исключение
[ ] Образы Docker собираются из проверенных баз; нет лишних пакетов

--- Инциденты и процессы ---
[ ] Контакты ответственных за ИБ; план реагирования на утечку секретов
[ ] Резервное копирование и шифрование БД в production (если применимо)
